# Student Task Manager 📝

A simple web-based task management application built using HTML, CSS, and JavaScript.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clean and responsive UI

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Purpose
This project was developed to practice frontend web development concepts such as:
- DOM manipulation
- Event handling
- Basic UI design
